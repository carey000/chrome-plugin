# 书签管理页优化说明（vBookmarks / Raindrop 调研 + 落地）

日期：2026-11-18

## 一、调研来源

| 工具 | 来源 | 性质 |
|---|---|---|
| vBookmarks | `https://windviki.github.io/vBookmarks` / Chrome Web Store（ID `odhjcodnoebmndcihdedenkmdmklpihb`）/ GitHub `windviki/vBookmarks` | 官方主页 + 商店页 + 开源仓库 README，功能点三方一致 |
| Raindrop.io | `https://www.raindrop.io/` / 帮助中心 `help.raindrop.io/filters`、`/import` / 官方博客 5.0 更新 | 官方主页 + 帮助文档 + 版本更新说明 |

两款工具的核心差异：

- **vBookmarks**：本地优先、键盘驱动、纯 Chrome 书签 API，强在「整理/清理」——模糊搜索、命令面板、暂存工作台、死链扫描、重复合并、撤销删除、本地访问统计、收藏夹分隔线、窗口→文件夹→标签组。
- **Raindrop.io**：云服务、跨端同步、强在「组织/检索」——集合嵌套、标签与筛选器（布尔组合、搜索运算符）、全文搜索、高亮批注、网页快照、四种视图、批量处理、导入导出、分享协作、提醒。

## 二、功能对照与取舍

| 功能点 | vBookmarks | Raindrop | 本次是否落地 | 说明 |
|---|---|---|---|---|
| 文件夹树侧栏 | ✓ 主视图 | ✓ 可拖拽调整宽度 | ✓ | 新增左侧常驻栏，折叠状态存 localStorage |
| 搜索 | ✓ 模糊匹配 + 高亮 + 历史 | ✓ 搜索即输入 + 运算符 | ✓（基础） | 标题/网址/标签/路径子串匹配，全局范围；**未实现**模糊算法、高亮、搜索历史、运算符 |
| 标签 | — | ✓ 核心能力 | ✓ | 标签存 `chrome.storage.local` 的 `bm_meta`（按 URL），侧栏标签筛选、编辑框内逗号分隔输入 |
| 星标/收藏 | ✓ 暂存区加星 | ✓ Favorites 过滤器 | ✓ | 卡片星标按钮 |
| 视图切换 | 七视图 | Grid/Headlines/Masonry/List | ✓（保留原有） | 原卡片/列表切换保留 |
| 排序 | 按文件夹排序 | 日期/标题/站点/手动拖拽 | ✓ | 新增标题/最近添加/域名排序；拖拽排序本就支持 |
| 批量操作 | ✓ 多选批处理 | ✓ 批量加标签/移动/删除 | ✓ | 卡片复选框 + 批量条：全选/加标签/移动/打开/删除 |
| 删除撤销 | ✓ 每次删除可撤销 | — | ✓ | 删除后 8 秒提示条，单个删除可撤销（含整棵子树） |
| 死链检测 | ✓ 批量扫描 + 代理复检 | ✓ Pro 功能 | ✓（沿用原有） | 原有 IntersectionObserver + HEAD/GET 复核保留 |
| 标签组 | ✓ 存为文件夹/重开为组 | — | ✓（沿用原有） | 原标签区块保留 |
| 快捷键 | ✓ 完整键盘流 | Ctrl+F 搜索 | ✓（基础） | `/` 聚焦搜索、`Esc` 清除/关闭、`Delete` 删除聚焦卡片、文本框 Enter 保存 |
| 命令面板 | ✓ Ctrl/Cmd+K | — | ✗ | 超出本次范围 |
| 重复书签合并 | ✓ 六种策略 | ✓ Pro 功能 | ✗ | 超出本次范围 |
| 访问统计/暂存区/分隔线 | ✓ | — | ✗ | 超出本次范围 |
| 全文搜索/快照/高亮批注 | — | ✓ | ✗ | 需远程抓取/存储，与本项目「零远程请求」原则冲突 |
| 导入导出/分享协作/提醒 | — | ✓ | ✗ | 云服务能力，本地扩展不适用 |

## 三、已落地的改动

| 文件 | 改动 |
|---|---|
| `bookmarks/bookmarks.html` | 顶栏加搜索框、排序下拉、新建书签/文件夹按钮；主体改「侧栏 + 内容」两栏；侧栏含文件夹树与标签筛选；加筛选条、批量操作条、撤销提示条；编辑弹窗加标签输入框 |
| `bookmarks/bookmarks.js` | 新增 `chrome.bookmarks.create/remove/move` Promise 包装；`bm_meta` 元数据（标签/星标）；文件夹树与标签列表渲染；全局搜索/排序/筛选；单选删除 + 撤销（含子树快照恢复）；多选批量操作；快捷键；保留原有死链检测与标签组逻辑 |
| `bookmarks/bookmarks.css` | 末尾追加新组件样式（工具栏/侧栏/标签/批量条/撤销条），未改上方原有规则 |

## 四、验证与边界

- `node --check bookmarks.js` 通过；HTML 引用 id 全部存在；标签平衡。
- **未在浏览器实测**：需重载扩展后逐项确认。
- 标签/星标存本地 `chrome.storage.local`，**不随 Chrome 书签云同步**，且按 URL 关联——URL 变更时会迁移到新 URL 的元数据。
- 标签筛选为单标签；搜索为子串匹配，非模糊搜索。
- 批量删除不可撤销（仅单项删除支持撤销）。
