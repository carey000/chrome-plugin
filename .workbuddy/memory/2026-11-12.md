## 第一轮：三栏 gap + tab-card 结构调整

- **三栏间距**：只给 `.page` 加 `gap: 12px`（`newtab.css:64`），其余 padding / 宽度 / 配色未动。注意 gap 是容器边框间距，各栏自带 padding（nav 右 14 / header·main 左 28 / side 右 20）会让内容视觉间距大于 12px；右栏 hidden 时不参与 flex gap 计算。
- **tab-card 三条**：① favicon 从卡片顶层移入 `.tab-card-title`，与标题同行；② 宽高抽成 `:root` 变量 `--tab-card-favicon-size: 20px`，并删掉原来的 `margin-bottom: 8px`；③ `.tab-card` 的 `min-height: 92px` 改成 `aspect-ratio: 16 / 9`。
- **实现要点**：`NT.el(tag, cls, text)` 用 `textContent`，不能直接塞 DOM 子节点 → 新建空 `.tab-card-title`，`appendChild(NT.favicon(...))` + `appendChild(NT.el('span','tab-card-title-text', text))`。标题改 `display:flex; align-items:center; gap:8px; min-width:0`，两行截断（`display:-webkit-box; -webkit-line-clamp:2`）移到新增的 `.tab-card-title-text` 上 —— 不包这层 span 则匿名文本无法被 flex 选中、clamp 会失效。
- **改动文件**：`newtab/sessions.js`（`makeTabCard`）、`newtab/newtab.css`（4 处：`:root` / `.tab-card-favicon` / `.tab-card` / `.tab-card-title` + 新类）。
- **验证**：全量 `node --check` 通过；新增 vm 冒烟 `nt-tabcard-test.js`（22 项断言，加载真实 `src/favicon.js` 校验 DOM 层级、img src、灰色占位回退、CSS 变量与 aspect-ratio）；上一轮 sessions 20 项 + 布局 26 项回归全 PASS。
- **未擅自处理 / 待确认**：favicon 进标题后，`.tab-card-del`（absolute 右上）hover 时可能压住标题第一行末尾文字，未加 `padding-right` 预留；`aspect-ratio` 不阻止内容撑高，长标题仍可能突破 16/9。

## 第二轮：open-tab 删除按钮 + main 圆角变量

- **需求**：① `.open-tab` hover 时末尾出现 × 图标用于删除；② `.main` 加 24px 圆角变量，与 `.wrapper` 一致。
- **删除语义判定**（未提问，按最合理默认实现）：Open Tabs 是 `chrome.tabs.query({})` 的实时列表，「仅从列表隐藏」刷新即恢复、无意义 → 实现为 `chrome.tabs.remove(tab.id)` 关闭浏览器里的真实标签页。若用户原意不同需改。关闭失败读 `chrome.runtime.lastError`；成功后显式 `renderOpenTabs()`，另有 `chrome.tabs.onRemoved` → `scheduleRefresh` 兜底。
- **结构改动**：`makeOpenTab` 外层 `<button>` 改 `div[role=button][tabindex=0]`（避免 `<button>` 内嵌 `<button>` 的非法结构），内部追加真 `<button class="open-tab-del">`，`event.stopPropagation()` 防止冒泡触发 `openInNewTab`。补 keydown Enter/Space 支持，并判 `event.target !== row` 时 return（焦点在 × 上按 Enter 不误开标签）。CSS 给 `.open-tab` 补 `cursor: pointer`（全局 `button{cursor:pointer}` 不再生效）。
- **圆角**：`:root` 新增 `--main-radius: 24px`；`.main` 与 `.wrapper` 都用 `border-radius: var(--main-radius) var(--main-radius) 0 0`，清掉硬编码 `24px 24px 0 0`。media query 里的 `.wrapper` 只改 padding，未受影响。
- **改动文件**：`newtab/sessions.js`、`newtab/newtab.css`（均沿用上一轮两个文件，未碰 common.js / HTML / manifest）。
- **验证**：`node --check`；新增 vm 冒烟 `nt-opentab-del-test.js`（22 项：DOM 层级、× 关闭真实标签、不冒泡、关闭后列表刷新、键盘不误触发、lastError 兜底、圆角变量共用、hover/focus-within/focus-visible 显隐）；三组旧回归（sessions 20 / layout 26 / tabcard 22）全 PASS。
- **已知行为**：新标签页自身也在 Open Tabs 列表里（`chrome-extension://` → `is-locked`），点它的 × 会关掉当前 newtab 页面；`is-locked` 行整体 `opacity: .55`，× 也跟着变淡但 hover 可见。二者均未额外处理。

## 第三轮：tab-card-host 贴底 + 集合刷新按钮改 SVG

- **需求**：① `.tab-card-host` 居于卡片最下方；② 集合头部的文字「刷新」按钮换成 `#refreshTabsBtn` 里的 SVG。
- **① 实现**：`.tab-card` 加 `display:flex; flex-direction:column`；`.tab-card-host` 的 `margin-top:6px` 改成 `margin-top:auto` + `padding-top:6px`（auto 贴底，padding 保证内容撑满时仍有最小 6px 间距）。`.tab-card-del` 是 absolute，不受 flex 影响。
- **② 实现**：`sessions.js` 顶部新增常量 `REFRESH_ICON`（path `M20 11a8 8 0 1 0-2.3 6M20 5v6h-6`，15×15，与 HTML 中 `#refreshTabsBtn` 逐字一致）；刷新按钮由 `NT.el('button','mini-btn','刷新')` 改为 `NT.el('button','icon-btn')` + `innerHTML = REFRESH_ICON` + `aria-label="刷新"`（无文字后必须补无障碍标签），`title` 说明保留。复用 `.icon-btn` 是因为它正是 `#refreshTabsBtn` 用的类，无需新增 CSS。
- **关键联动（易漏）**：`flashButton()` 原本用 `textContent` 存/恢复，会把 SVG 冲成字符串 → 改为保存/恢复 `innerHTML` + `className`；flash 期间临时切成 `mini-btn` 显示「窗口已关闭」/「无可保存标签」，1.8s 后还原 `icon-btn` + SVG。项目里 CARET_ICON / PENCIL_ICON 早已用 innerHTML 注入 SVG，CSP 下可行。
- **改动文件**：`newtab/sessions.js`、`newtab/newtab.css`。测试脚本 `nt-sessions-test.js`（临时文件）的按钮定位从 `textContent==='刷新'` 改为 `aria-label==='刷新'`，否则会误报「按钮顺序」失败。
- **验证**：全量 JS `node --check` + manifest JSON 通过；四组回归（sessions 20 / layout 26 / tabcard 扩展至 34 / open-tab 22）全 PASS。新增断言覆盖 SVG path 与 HTML 完全一致、flex column、margin-top:auto、flash 保存/恢复机制（源码级）。
- **待浏览器实测**：flash 提示结束后 SVG 在真实 DOM 中的重建（vm mock 的 innerHTML 不解析子节点，只做了源码断言）；`.icon-btn` 26px 与旁边 `.mini-btn` 28px 的高度观感。
