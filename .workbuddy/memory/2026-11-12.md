## 移动端布局崩坏修复（只改 CSS）
- **现象**：356×751 视口下三栏内容重叠、文字竖排单字、红色按钮被压成圆、header 时间与 Open Tabs 内容叠在一起。
- **根因（由 CSS 规则推算）**：`@media (max-width: 1100px)` 把 `.side` 改为 `flex-basis: 210px`，而旧的 `@media (max-width: 560px)` **完全没处理右栏**；同时把 `.nav` 收窄到 60px。于是 `356 - 60 - 210 - 12*2 = 62px` 留给 `.workspace`，所有内容被压到 62px 宽。次要因素：`@media (max-width: 900px)` 给 `.header`（flex column）加了 `flex-wrap: wrap`。

## 市面新标签页插件功能调研（零代码改动）
- **产物**：`docs/newtab-feature-research.md`（323 行）。本轮**未改任何 js/css/html/manifest**；`git status` 里的 M 文件全是前几轮累计未提交。
- **方法**：并行调研国内 8 类（iTab / WeTab / Infinity / 青柠 / 简Tab / MONKNOW / BdTab / 抓鱼鸭）+ 海外 19 款（Momentum / Toby / OneTab / Start.me / Session Buddy / Workona / Bonjourr / Nighttab / Tabliss / Tab Manager Plus 等），每条功能标【官方商店/官网/官方帮助/第三方/摘要/推断】；本地代码由 Explore 子代理全量盘点（文件+行号）。直接抓取 5 个 Chrome 官方 API 文档核对权限与配额。
- **核心结论**：市面分「视觉装饰型」与「标签治理型」两条路线；后者是扩展 API 独占、网页版起始页做不到，而本项目已做一半 → 优先补完标签治理链路，而不是加新组件。
- **分级建议**：P0 = ① 导入导出/本地备份（当前 7 个 key 无备份，卸载即丢）② 一键收纳（保存+关闭原标签，已有保存/新窗口恢复，只差关闭）③ 网址导航可视化增删改（`sites-data.js` 写死 15 条、7 条 tentative）；P1 = 重复标签检测 / `sessions` 最近关闭（MAX 25，需新增权限）/ `storage.sync` 免账号同步设置 / 深浅色+本地背景；P2 = 统一搜索命令面板 / omnibox 关键字 / 纯本地小组件。
- **明确不建议**：天气热搜股市汇率 RSS、AI、在线壁纸库、账号云同步后端、`tabs.discard` 挂起、站点拦截、全局快捷键（用户此前明确删过）、Vue/React 构建链、`topSites`。
- **零成本机会**：`manifest.json` 已声明但零调用的 5 个权限中，`contextMenus` 可直接支撑「右键添加当前站点」，无需改 manifest / 无需 reload。
- **精确性纠错（写进文档 §5）**：旧方案把「农历 / 亲戚称呼计算器」与天气并列为需接口功能是错的 —— 农历已用 `Intl.DateTimeFormat('zh-CN-u-ca-chinese')` 零接口实现，亲戚称呼也是纯本地规则计算；真正需接口的是天气/热搜/股市/汇率/RSS/在线壁纸/翻译/IP/AI。按用户意图，整类装饰型小组件本期仍不纳入，P2-3 仅列可选。
- **已核实的官方硬约束**：`storage.sync` 配额 `QUOTA_BYTES 102400` / `PER_ITEM 8192` / `MAX_ITEMS 512` / 1800 次每小时 / 120 次每分钟，`unlimitedStorage` 不提升 sync 配额 → 只能同步设置类小数据，**不能同步 `nt_collections`**；`sessions` 权限 + `MAX_SESSION_RESULTS=25`；`omnibox` 需 manifest key 但无 permissions 项，与 `chrome_url_overrides.newtab` 共存**官方文档既未禁止也未确认，需实测**；`tabs.discard` 权限官方文档未明确；`topSites` 返回数量未写明。
- **待用户定 4 件事**：收纳是否默认关闭标签（OneTab vs Toby）；要不要 `storage.sync`（不能满足标签集跨设备）；P2-3 小组件是否真不做；有无实机截图做视觉校准。文档含总控 + P0-1 可复制实施提示词与 4 阶段验收顺序。
